# Нидерланды 2

Отдельный 3X-UI/Xray на `amnez_ni` (`45.10.166.46`), только для продукта
`club` («МОЖНО Клуб»). Публичный VLESS/XHTTP/TLS inbound — `11443/TCP`, ID 1.
Имя профиля — `🇳🇱 МОЖНО • Нидерланды 2`, код сервера — `nl2`.

Контейнер `xray-nl2` ограничен 0,75 CPU и 512 МБ RAM, не имеет Linux capabilities
и не запускает Fail2ban. Host network сохраняет действие UFW и не создаёт
новых Docker NAT-правил. Caddy, AmneziaWG и Medcluben не перезапускаются.

Используется уже существующий сертификат `srv2.amneziya.mozhno.org` из
каталога Caddy, подключённого только для чтения. DNS и Caddyfile не меняются.
Панель `2053/TCP` и внутренние подписки `2096/TCP` разрешаются UFW только
с `mozhno_bot` (`45.89.63.246`); внешний VPN-порт — `11443/TCP`.

`bootstrap-local.py` готовит свежую SQLite локально в указанном приватном
каталоге, используя официальный Docker-образ. Секреты и SQLite в Git не входят.
В production доставляется только готовое состояние новой панели; исходники
Compose поступают из Git той же версии, что и сервис подписок.

Точка возврата приложения: `rollback/pre-xray-nl2-20261026`.
Для отката сначала убрать назначение `club-nl2-direct` из продукта, вернуть
конфигурацию сервиса подписок, затем остановить только `xray-nl2` и удалить
только добавленные правила UFW для 11443, 2053 и 2096.

Установка считается завершённой после сквозной проверки нового профиля,
проверки прежних профилей и сравнения контейнеров, файлов конфигурации,
публичного ключа и peers Amnezia с сохранённым состоянием до установки.
