# «МОЖНО» голосом Кати

Это второй комплект документов сообщества. Содержание и правила те же, что в основной версии, но язык живее: с личной интонацией, самоиронией, конкретикой и характером «РадиоКати».

- [Манифест](./manifesto.md) — чтобы почувствовать, что это вообще за люди и зачем они собрались.
- [Памятка участника](./participant-guide.md) — чтобы зайти в клуб и не утонуть в количестве тем.
- [Карта сообщества](./community-map.md) — весь клуб на одном листе, без философского тумана.
- [Внутренний Canvas](./internal-canvas.md) — рабочая версия для Кати и команды: что бережём, как принимаем решения и куда идём.

Это не тексты «под публикацию без просмотра». Авторский голос очень личный, поэтому перед публикацией Катя проверяет каждую версию и меняет формулировки, которые ей не принадлежат.
