# Сообщества и клубные механики

Статус: исследовательские материалы и предложения.
Применение к продукту требует отдельного подтверждения.

Этот каталог собирает знания о создании и развитии онлайн-сообществ, которые
могут быть полезны для Clubni.

## Содержание

- [Механики сообщества](mechanics.md) — репутация, признание, роли, ритуалы,
  взаимопомощь и участие.
- [Книги, статьи и курсы](resources.md) — проверенные материалы и рекомендуемый
  порядок изучения.

## Основной принцип

Аудитория потребляет контент, а сообщество создаёт отношения и совместные
действия. Поэтому клубные механики должны помогать участникам:

- замечать и признавать вклад друг друга;
- знакомиться и выстраивать доверие;
- получать и оказывать помощь;
- участвовать в общих делах;
- постепенно брать на себя новые роли и ответственность.

Баллы, рейтинги и награды полезны только тогда, когда поддерживают эти действия,
а не становятся самостоятельной игрой.
