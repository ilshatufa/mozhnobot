## Что проверено и исключено

- ChatBat содержит ТЗ и каркас программного community-бота, но не отдельное
  исследование построения сообщества.
- Challenge содержит ТЗ продукта для челленджей, но не методический документ о
  развитии клуба.
- Остальные документы Clubni посвящены программному продукту, платежам,
  подпискам, UX, QA и развёртыванию.
- Общие Telegram-инструкции, VPN-документы, клубный контент, сырые выгрузки,
  чужие курсы и случайные упоминания слова «сообщество» не копировались.

## Правило обновления

Новый внешний материал добавляется только если его основная тема — построение,
исследование или управление сообществом. Для каждой копии фиксируются источник,
дата снимка и статус. Техническая документация продукта остаётся вне этой
библиотеки.
